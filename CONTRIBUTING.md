# Contributing

Thank you for your interest in the Amadeus Travel Toolkit.

## Contribution policy

**We are not accepting external pull requests or code contributions.** To ensure the technical accuracy and API correctness of the guidance provided here, all skills must undergo a rigorous internal verification process by the Amadeus teams that own the underlying APIs.

Every file in this repository is generated from an internal source of truth and republished automatically, so an edit made here would be overwritten rather than kept.

## How you can help

While we do not accept direct code contributions, your feedback is genuinely valuable:

1. **Report an issue.** Wrong endpoints, missing required parameters, response shapes that don't match reality, or guidance that leads an agent to write broken code - all worth reporting at [Issues](../../issues). If an agent loaded a skill and still produced wrong code, include the prompt you used and the code you got back.

2. **Request a new skill.** If there's an Amadeus API you'd like covered, or a pattern that spans several of them, open a request.

3. **Remix and share.** Fork these skills and adapt them to your own workflows. That's encouraged, and we'd like to hear about what you build.
